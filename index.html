03 / ENGINEERING NOTES

Mathematics meets
CSS animation.

Each planet travels around the Sun through a dedicated CSS animation. Nested orbital containers create independent motion for moons, while focus and hover states reveal planet information and pause selected orbital animations. The speeds and dimensions are illustrative design values, not a scientifically scaled orbital simulation.
